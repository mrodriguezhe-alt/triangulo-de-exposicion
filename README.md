# Triángulo de Exposición

> **Estado:** idea en fase de planificación. Todavía no existe un prototipo.

## ¿Qué es?

Una app móvil pensada para simular una cámara, de modo que las personas aprendan los comandos y configuraciones de una cámara real.

## Problema o necesidad

Aprender fotografía normalmente exige tener una cámara y conocer sus
configuraciones desde el inicio. Quien no tiene una cámara, o nunca ha usado
una, parte con desventaja: no puede practicar ni entender cómo se relacionan
ISO, apertura, velocidad de obturación y enfoque. Este proyecto busca ofrecer
un espacio de práctica que no dependa de tener el equipo.

## ¿Para quién es?

Para personas que nunca han usado una cámara o que no tienen acceso a una.

## Origen

La idea nació durante un curso de fotografía que realizamos en el club. Allí
notamos que muchos participantes llegaban sin conocimientos previos de cómo
funciona una cámara, y que esa falta de base dificultaba aprovechar el curso.
De esa necesidad surgió la idea de crear una herramienta que les permita
familiarizarse con los comandos de una cámara antes de usar una real.

## Visión del proyecto

Lo siguiente son ideas, no funciones existentes:

- La persona ingresa sus datos y se crea una carpeta donde puede ver sus trabajos y su avance.
- Al inicio, la app da indicaciones sobre cómo usarla.
- Después, propone retos en forma de sesiones que ayudan a subir de nivel y a conocer más configuraciones.
- Idea a explorar: retos semanales de creación de imágenes con las configuraciones aprendidas.
- Idea a explorar: usar la cámara del teléfono para dar más realismo.

## Lo que se quiere enseñar primero

- ISO
- Apertura
- Velocidad de obturación
- Enfoque
