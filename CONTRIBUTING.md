# Cómo contribuir

¡Gracias por tu interés! Este proyecto está en una etapa muy inicial y por ahora lo lleva una sola persona. Todavía no hay código, así que las formas de ayudar son sencillas.

## Formas de ayudar ahora

- Comentar o proponer ideas en los Issues.
- Investigar si los teléfonos permiten controlar la cámara (ver el Issue abierto sobre esto).
- Sugerir ideas de retos para aprender ISO, apertura, velocidad de obturación y enfoque.
- Dar opiniones sobre cómo debería verse y sentirse la app para alguien que nunca ha usado una cámara.

## Cómo proponer algo

1. Revisa los Issues abiertos para no repetir una idea.
2. Abre un Issue nuevo con un título claro.
3. Explica qué propones y por qué ayudaría a quien aprende.
4. Si afirmas algo técnico, indica de dónde lo sacaste para poder verificarlo.

## Pull requests

Por definir. Todavía no hay código ni tecnología elegida. Cuando existan, este apartado se actualizará.

## Trato respetuoso

Este es un proyecto pensado para personas que están empezando. Pedimos un trato amable y paciente con todas las preguntas.
